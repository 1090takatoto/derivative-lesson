# 微分係数 ― 平均変化率から接線の傾きへ

高校数学（数学II「微分係数」）の授業用インタラクティブ教材。

**[index.html](index.html) をブラウザで開くだけで動きます。** 外部ライブラリもネット接続も不要なので、会場のネットワーク環境に左右されません。

## 何ができるか

グラフ上の2点 A(a, f(a))、B(a+h, f(a+h)) を通る**割線**と、点 A における**接線**を同時に表示します。点 B をドラッグして A に近づけると、割線が接線に重なっていきます。この過程が微分係数の定義そのものです。

画面はグラフと操作パネルの左右2分割。数値はパネル最下部にまとめてあるので、**パネルを閉じればグラフだけを大きく見せられます**。

```
                f(a+h) − f(a)
f′(a) =  lim  ─────────────────
        h→0          h
```

## 授業での使い方（進行例）

**1. 平均変化率を確認する**（h = 2 程度）
点 A と B を結ぶ直線＝割線を見せ、その傾きが平均変化率であることを確認します。右上の大きな数値と、その下の計算式（`( 4.000 − 1.000 ) ÷ 2.000 = 1.500`）が板書と対応します。

**2. B を A に近づける**
グラフ上で点 B をドラッグして A に寄せます。パネル最下部の数値が `3.000 → 2.500 → 2.100 → 2.010 → 2.001` と一定の値に近づいていきます。

**3. h を 0 にできないことを示す**
B をどれだけ A に近づけても h は 0.001 が下限で、完全には重なりません。**0 にはできないが、いくらでも 0 に近づけられる**——極限を導入する場面です。

**4. 接線と重ねる**
**接線は既定で表示されません。** h を小さくして「割線がある向きに落ち着いていく」ことを先に見せ、その後でヘッダの「接線を表示する」を押すと、割線がすでに接線と重なっていることが確認できます。答えを先に見せない構成です。

「h を 0 に近づける」の[開始]でアニメーション表示もできます。速さは3段階（ゆっくり 約13秒 / ふつう 約5秒 / はやい 約2.5秒）。既定は最も遅い設定で、説明しながら見せられるようにしてあります。

アニメーションは **h = 0.001 で停止します**。2点はほとんど重なりますが、完全には一致しません。h を 0 そのものにはできないという事実をそのまま見せる形にしています。

**5. 反対側からも近づける**（発展）
点 B を A の左側までドラッグすると h が負になります。どちら側から近づけても同じ傾きに向かうことを確認できます。

## 操作

**点 A・点 B はグラフ上で直接ドラッグして動かします。** サイドパネルは「h を 0 に近づける」「関数を変える」「数値」の3つだけです。

ヘッダのボタンは左から以下の3グループ。

| ボタン | 働き |
|---|---|
| パネルを隠す | グラフを全画面に |
| 文字を大きく | 文字倍率 1.0 → 1.3 → 1.6 |
| 接線を表示する / 座標を表示 / 補助線を表示 / 整数に止める | 押すたびに切り替わり、オンのボタンは緑になる |
| ズームを戻す | 拡大・スクロールだけを初期位置へ（点や関数はそのまま） |
| すべて初期化 | 点の位置・関数・各種設定をすべて初期状態へ |

既定は「自由に動かす」（0.001 刻み）です。「整数に止める」を押すと、点をドラッグしたときに整数の近くで磁石のように吸い付きます。

画面幅 700px 以上ではグラフと操作パネルが左右に並びます（iPad は縦向きでも横並び）。iPhone の縦向きなど狭い画面では、パネルがグラフの下に回ります。

**画面上に操作説明は出していません**（当日は iPad で操作する想定のため）。操作方法は下の表にまとめてあります。

iPad などのタッチ操作でも、マウス操作でも同じように動きます。

| 操作 | 方法 |
|---|---|
| 点 A・B を動かす | 点をドラッグ、または各セクションのボタン・x 座標の入力欄 |
| 画面を移動 | 背景をドラッグ |
| 拡大・縮小 | 2本指ピンチ（iPad）、マウスホイール |
| 接線の表示切替 | ヘッダの「接線を表示する」、または <kbd>T</kbd>（既定は非表示） |
| アニメーション | 「h を 0 に近づける」の[開始]、または <kbd>Space</kbd> |
| サイドパネル開閉 | ヘッダのボタン、または <kbd>P</kbd> |
| A を動かす | <kbd>←</kbd><kbd>→</kbd>（0.1刻み / Shift で1 / Alt で0.001） |

キーボードショートカットは PC で操作する場合のみ使えます（iPad では画面のボタンで操作してください）。

## 教室で使うときの設定

- **文字を大きく** — ヘッダのボタンで 1.0 → 1.3 → 1.6 倍。投影時は後方の席から読めるサイズに
- **パネルを隠す** — グラフだけを全画面に。説明に集中させたい場面で
- 明るい教室での投影を前提に、配色は白背景で固定しています

## 扱える関数

プリセット：x² / sin x / x³/8 − x / √x / 1/x / eˣ

入力欄に任意の式も書けます。`x^2` `sin(x)` `x^3/8-x` `sqrt(x)` `1/x` `exp(x)` `log(x)` `2*pi*x` など。`log` は自然対数（底 e）です。

プリセット関数は解析的な導関数を持っているため f′(a) が厳密値で出ます。手入力した式は中心差分による数値微分（誤差 1e-5 程度）で近似します。

定義域外の点（√x で x < 0 など）を指定すると、その旨を明示します。定義域の指導にも使えます。

## 設計上の注意点

- **x 軸と y 軸のスケールを共通**にしているため、画面上の傾きが数学的な傾きと一致します。傾きを扱う教材でここが崩れると意味がありません
- **1/x のような不連続点**では、隣り合う描画点が大きく跳んだ箇所で線を切り、存在しない漸近線が描かれないようにしています
- **ラベルは重ならないように自動配置**しています。座標タグと補助線のラベル（h、f(a+h)−f(a)）は近い位置に出るため、先に矩形を確保し、重なる候補を捨てて次の候補（点の反対側など）に回します
- **点の名前は大文字 A・B、その x 座標は小文字 a**。混同を避けるため、操作パネル側の表記は「A の x 座標」「A を x = 1 へ」のように点の名前で統一している（`A = 1` とは書かない。点と数を等号で結ぶのは不正確なため）
- **h の最小値は 0.001**。これ以上小さくすると浮動小数点の桁落ちで平均変化率が暴れ、かえって収束が見えにくくなります
- **点 A・B とも x 座標で指定する**（B を h で指定していたが、A と操作が揃わず分かりにくかった）。h は結果として決まる値なので「数値」セクションに現れる
- **アニメーション中は b を 0.001 刻みに丸めない**。丸めると1ステップの減少量が丸め幅に飲まれ、h が 0.02 付近で停滞して終了条件に到達しなくなる
- 式の入力は識別子のホワイトリスト方式で検査しています（`x`、円周率、登録済み関数名のみ）。文字種チェックだけでは `alert(1)` のような任意コードが通ってしまうため
